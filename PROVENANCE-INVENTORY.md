# CAD provenance inventory

The private catalog scanned Isaiah's Mac and Orion CAD roots on 2026-09-12. It found 6,659 file instances representing 3,249 unique payloads.

| Classification | File instances | Public handling |
|---|---:|---|
| Created | 5,597 | Review and consolidate by logical project and final revision |
| Edited/remixed | 283 | Hold until the source creator, source URL, licence, and modification history are verified |
| Downloaded | 588 | Exclude from Isaiah-authored releases |
| Unknown | 191 | Exclude until provenance is established |

The created count is not a count of publishable models. It includes duplicated Mac/Orion copies, historical build runs, STEP/STL pairs, keepout/reference solids, non-printable application assets, and intermediate revisions. Printables releases are therefore grouped by a coherent design project, and only the latest supported artifacts are published.
