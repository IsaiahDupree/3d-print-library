# Media Travel Case for T7 Shield, USB and microSD

[Download on Printables](https://www.printables.com/model/1912974-media-travel-case-for-t7-shield-usb-and-microsd)

A modular storage case with six bays for Samsung T7 Shield drives, five rectangular USB bays and twelve numbered microSD slots. This release pairs the R17 shell and lid with the R21 downward-release clips and the matching rear hinge sleeves.

The ZIP contains the four print-oriented STL files, individual STEP files for the base, lid and front clip, an assembly STEP and hardware notes. Print the base and lid separately. The sleeve and clip plates each contain two parts. The build requires six M3 heat-set inserts, two M3 × 35 rear screws and four M3 × 40 front screws. Measure the actual fasteners and inserts before fitting them.

The USB pockets use a 22 × 15 × 68 mm sizing envelope. Check the media and connectors you plan to carry. The cover is an Orion render with illustrative media. The shell uses a rigid mating seam. Physical fit, loaded retention, fatigue, water resistance and drop protection remain unqualified.
